## 🎮 项目简介

本项目是对经典移动端 3D 射击游戏《Tank Hero 2 Laser Wars》的核心机制复刻。
游戏包含多维度的坦克操控、丰富的武器系统（物理反弹、激光穿透、声波渐变）、多逻辑的 AI 敌人以及复杂的环境交互机制。通过此项目，我全面展示了在 3D 游戏开发中的架构设计、物理计算、性能优化以及系统统筹能力。

⚠️ **【关于美术资源的特别说明】**
> 本项目核心侧重于**程序逻辑与架构实现**。游戏内使用的 3D 模型与美术素材由同期参与考核的美术实习生提供。由于时间紧迫及非强绑定合作关系，部分素材可能存在未上色（白模）、贴图丢失或渲染故障等现象，**这不代表本项目的最终程序质量**。敬请将目光聚焦于功能实现与代码逻辑。

## ✨ 核心技术亮点 (Technical Highlights)

在满足基础考核要求之上，我独立完成了以下**进阶系统**与核心技术难点：

### 1. ⚙️ 性能优化：全局对象池系统 (Object Pooling) [进阶功能]
- 针对游戏中大量高频生成的物体（如炮弹、激光、特效、敌方坦克），设计并实现了一套高扩展性的全局对象池。
- 彻底消除了运行时的频繁 `Instantiate` 和 `Destroy` 造成的 GC (垃圾回收) 卡顿，确保游戏在复杂的弹幕交火环境下依然保持高帧率运行。

### 2. 💾 数据管理：持久化存档系统 (Persistent Data) [进阶功能]
- 实现了玩家游戏进度的本地序列化存储。
- 记录并持久化玩家的**关卡解锁进度**、**音效/音乐设置**及**镜头跟随偏好**，确保玩家在杀后台或重启游戏后能无缝恢复上次的游戏状态。

### 3. 📐 复杂的武器与物理碰撞系统
- **物理反弹算法**：利用 `Vector3.Reflect` 与射线检测，精准实现普通炮弹在多边形墙壁间的多次物理反弹逻辑。
- **多武器形态解耦**：利用面向对象编程（多态/接口），实现了差异化极大的武器系统：
  - **双管炮**：多发射点向量计算。
  - **激光炮**：无视物理碰撞的射线穿透逻辑。
  - **声波炮**：随飞行时间/距离动态 Lerp 放大碰撞体与特效的渐变系统。

## 🚀 已实现功能清单 (Features)

本项目严格按照任务书完成了所有**基础功能**及部分核心**进阶功能**，搭建了 5 个机制完备的测试关卡。

### 🪖 玩家与控制系统
- **分离式控制**：WASD 控制底盘移动与朝向，鼠标控制炮台独立旋转与瞄准。
- **动态表现**：实现了开火时的炮管后坐力位移，以及平滑的摄像机死区跟随机制。

### 👾 敌人 AI 系统
- 实现了具备状态切换的敌人 AI，包括：**随机游走、追踪玩家、自动开火**。
- 开发了四种具有不同武器配置的敌人：**杂兵**（普通反弹炮）、**天启**（双发炮）、**棱镜**（激光穿透）、**塞壬**（声波渐变）。

### 🧱 动态地形与交互环境
- **物理墙壁**：阻挡一切并触发子弹反弹。
- **红蓝激光墙过滤**：红墙（挡坦克、透子弹），蓝墙（透坦克、挡子弹）。
- **机关伸缩墙**：受击后按特定时间轴下沉与恢复，需配合判定上方是否有坦克以防止穿模重叠。

### 🕹️ 完整的 UI 交互流
- 搭建了 游戏主菜单 -> 关卡选择（带解锁逻辑） -> 游戏内 HUD（血条、提示） -> 暂停/设置面板 -> 结算界面（胜利/失败） 的完整闭环流程。
